# Support

Use [DIDMail Discussions](https://github.com/orgs/didmail-org/discussions) for
public questions, integrations and early design conversations. Support is
community-based; there is no guaranteed response time.

| Need | Where to go |
| --- | --- |
| Usage, setup or an integration question | [Q&A](https://github.com/orgs/didmail-org/discussions/new?category=q-a) |
| A feature idea or design alternative | [Ideas](https://github.com/orgs/didmail-org/discussions/new?category=ideas) |
| A demo or documented experiment | [Show and tell](https://github.com/orgs/didmail-org/discussions/new?category=show-and-tell) |
| A reproducible defect in a component | Its repository's issue tracker; see the [repository map](README.md#find-the-right-repository) |
| A correction to this forum's guidance or forms | A pull request to this repository |
| A possible vulnerability or exposed credential | The [private security reporting process](SECURITY.md) |
| Harassment or other conduct concerns | The [community conduct reporting process](CODE_OF_CONDUCT.md#reporting-and-moderation) |

For technical questions, include versions, the smallest reproduction, relevant
sanitized errors and what you have already tried. Share synthetic examples
instead of real mail or wallet data. A public question should not contain
exploitable security details.

DIDMail maintainers can help investigate ArcBlock/ARC integration questions,
but this is a DIDMail forum, not an official ArcBlock support queue. Upstream
maintainers may participate; their presence does not imply a response-time or
hosting commitment.
