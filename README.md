# DIDMail Discussions

The community forum for DIDMail: ask questions, explore ideas, share experiments,
and discuss work across the project's repositories.

**[Open the forum](https://github.com/orgs/didmail-org/discussions)** ·
[Ask a question](https://github.com/orgs/didmail-org/discussions/new?category=q-a) ·
[Project overview](https://github.com/didmail-org/overview) ·
[Website](https://didmail.org/)

欢迎使用中文或 English 交流。这里用于 DIDMail 的使用问答、技术讨论、想法和实践分享；
明确的代码缺陷请提交到对应组件仓库，安全问题请走[私密报告渠道](SECURITY.md)。

## Choose a category

| Category | Use it for |
| --- | --- |
| [Q&A](https://github.com/orgs/didmail-org/discussions/categories/q-a) | Usage, setup, integration and troubleshooting questions. Mark a reply as the answer when it resolves your question. |
| [Ideas](https://github.com/orgs/didmail-org/discussions/categories/ideas) | A problem to solve, a proposed feature, or a design trade-off. |
| [General](https://github.com/orgs/didmail-org/discussions/categories/general) | Introductions and conversations that do not fit another category. |
| [Show and tell](https://github.com/orgs/didmail-org/discussions/categories/show-and-tell) | Demos, experiments, guides and lessons learned. State what was actually tested. |
| [Announcements](https://github.com/orgs/didmail-org/discussions/categories/announcements) | Maintainer updates, release information and changes affecting the community. |
| [Polls](https://github.com/orgs/didmail-org/discussions/categories/polls) | Focused questions with explicit choices. A poll is input to a decision, not a release commitment. |

Before posting, search existing discussions and read the relevant component's
documentation. Include exact versions, expected behavior and a small sanitized
example when applicable. Keep one main topic per discussion and link related
threads instead of repeating them. Responses are provided on a best-effort basis.

An ongoing integration question:
[running a complete ARC runtime on an owned Cloudflare account](https://github.com/orgs/didmail-org/discussions/1).

## Find the right repository

| Repository | Responsibility |
| --- | --- |
| [overview](https://github.com/didmail-org/overview) | Shared product documentation, architecture, development and release status |
| [protocol](https://github.com/didmail-org/protocol) | Protocol SDK, specifications, schemas and compatibility fixtures |
| [server](https://github.com/didmail-org/server) | Server, ARC integration, Cloudflare Workers and server UI |
| [extension](https://github.com/didmail-org/extension) | Browser extension |
| [mobile](https://github.com/didmail-org/mobile) | React Native client |
| [desktop](https://github.com/didmail-org/desktop) | Flutter client and its supported targets |
| [didmail-org.github.io](https://github.com/didmail-org/didmail-org.github.io) | Public website |

This repository contains forum guidance and category forms. Application code and
reproducible bug reports belong in their owning component repository. Cross-project
questions can start here; maintainers can link them to a scoped implementation issue.
